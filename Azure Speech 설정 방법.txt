Azure Speech 설정 방법

■ Region
koreacentral

■ Speech Key (Key 1)
팀 채널/DM으로 전달받거나, Azure 포털 → nova-speech → 키 및 엔드포인트 → Key 1 복사
(GitHub/Git에는 올리지 않음)

■ 프로젝트에 넣는 방법
1. `현진` 브랜치 pull
   git pull origin 현진

2. `Config/LocalNovaVoice.ini.example` 복사해서
   `Config/LocalNovaVoice.ini` 로 이름 변경

3. 파일 내용:
[/Script/NovaUproject.NovaVoiceSettings]
AzureSubscriptionKey=여기에_Key1_붙여넣기
AzureRegion=koreacentral
AzureLanguage=ko-KR

4. UE5 에디터 재시작 후 PIE(Play) 실행
5. 마이크 권한 허용
6. 화면에 "Voice listening: ..." 뜨면 OK

■ 무선 헤드셋(블루투스) 마이크가 안 될 때
1. Windows 설정 → 소리 → 입력 → **Hands-Free / AG Audio** 장치 선택 (Stereo는 마이크 없음)
2. PIE 실행 후 실패하면 화면에 **감지된 마이크 목록**이 표시됨
3. `LocalNovaVoice.ini`에 장치 이름 일부 지정:
   CaptureDeviceName=Hands-Free
   (예: "AG Audio", 헤드셋 모델명 일부도 가능)
4. 그래도 안 되면 키보드 1~4 / F5~F8로 테스트, 발표용은 USB 유선 마이크 권장

■ 음성 테스트
특별히 누를 키 없음. PIE 켜두고 마이크로 말하면 됨.
- "방패", "활", "낫", "검", "도와줘"

■ 키보드로 테스트 (음성 없이)
- 1 검 / 2 활 / 3 낫 / 4 방패
- F5~F8 보스 상쇄 윈도우 테스트
