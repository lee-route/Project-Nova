4. 정식 콘텐츠 — quest_abandoned_cargo
--------------------------------------------------------------------------------
  제목: 밀수업자의 버려진 화물
  데이터: quests-draft.json (의뢰인 3명)

  의뢰인 / quantityMode
    guard_timid      dramatic
    merchant_greedy  dramatic
    scholar_alric    faithful

  turn-in 수신: scholar_alric (의뢰인별 turnInTarget)

  기본 보고문 예:
    "안개 계곡에 밀수 화물이 버려져 있다. 마약초 열두 개가 들어 있다"

  outcome (interpreted 수량·확신 기준)
    authority_path    qty ≥ 10, certainty ≥ 0.6 → gold 150, cargo→authority
    black_market_path qty ≤ 9, certainty ≥ 0.4  → gold 300, cargo→black_market
    fallback          그 외                    → gold 80,  destination unknown

8. 로컬에서 체험하는 방법
--------------------------------------------------------------------------------
  A) 브라우저 (전체 파이프라인 UI)
     1) index.html 을 정적 서버로 연다
     2) Quest Playtest → 의뢰인 선택
     3) Accept Quest / Next Step / Run Full Flow
     4) Game State에서 gold, worldFlags.cargo_destination 확인

  B) HTTP API (UE와 동일 계약) — 연동 시작
     1) npm run api  (또는 node npc-api-server.mjs)
     2) npm run api:smoke  (연동 확인)
     3) POST /v1/quest/turn-in — API-QUICKSTART.md / ue-bridge/INTEGRATION.md
     4) GET /v1/quest/meta — 의뢰인 목록
     5) 응답 outcome → UE 세이브 반영

10. 팀 합의 사항 (진행 시 혼동 방지)
--------------------------------------------------------------------------------
  - Authoritative save = 언리얼. API sessionKey·QuestGameState는 서버 RAM 데모.
  - v1 API: turn-in + parse 중심. LLM·travel·full flow는 v2 또는 UE 로컬.
  - knowledgeAudit / WorldTruth: v1에서 게임 판정에 쓰지 않음 (로그·디버그).
  - 퀘스트 완료 판정 = interpretedFacts only (파서 원문·플레이어 입력 직접 X).
