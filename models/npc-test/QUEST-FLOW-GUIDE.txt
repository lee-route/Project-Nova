1. 한 줄 요약
--------------------------------------------------------------------------------
  의뢰인 NPC가 퀘스트를 준다 → 안개 계곡 조사(UE 연출) → 학자 알릭에게 보고
  → 엔진이 분기·보상 결정 → 성공 시에만 완료 대사·골드.

  · 보고(turn-in) 수신 NPC = scholar_alric 고정 (의뢰인에게 다시 보고하지 않음)
  · 판정 = completion.completed (단계 진행·HTTP ok 와 무관)
  · 「세계의 길잡이」 등 = UE placeholder — npcs.json 표시명 사용


2. 이야기 & 등장인물
--------------------------------------------------------------------------------
  배경
    안개 계곡에 밀수 화물이 버려졌다. 마약초 등 위험 물자 소문.
    마을은 공식 인도(관청) vs 암시장 유입 중 선택해야 한다.

  플레이어 (카엘)
    현장 확인 후 한국어로 조사 결과를 직접 입력·보고한다.

  의뢰인 — 택 1 (giverId)
    guard_timid      소심한 경비   — dramatic, 수량 과장
    merchant_greedy  탐욕한 상인   — dramatic
    scholar_alric    학자 알릭     — faithful, 숫자 충실

  보고 NPC — 항상 scholar_alric
    경비·상인에게 의뢰받아도 최종 보고는 알릭에게.


3. 플레이 흐름 (성공 / 실패)
--------------------------------------------------------------------------------

  ┌──────────────────────────────────────────────────────────────────┐
  │ ① 의뢰     의뢰인 대화 → giver_presume (지레짐작 수량 말함)   │
  │ ② 조사     안개 계곡 이동 · 화물 확인 (UE 맵 연출)               │
  │ ③ 보고     알릭 → 플레이어 입력 → turn-in                        │
  │ ③b         alric_presume (알릭이 해석 수량 말함 · 결과 전)       │
  │ ④ 결과     completion.completed ? 골드·행선 : 실패             │
  └──────────────────────────────────────────────────────────────────┘

  수량 연출 예 (경비 의뢰 · 플레이어 12개 보고)
    ① 경비: 「15개는 될 거야」(소문 12 → dramatic)
    ③ 플레이어: 「마약초 열두 개」
    ③b 알릭: 「15개군…」(기록 15 — 플레이어 12를 되풀이하지 않음)
    ④ 관청 150골드

  엔진 파이프라인 (③)
    scenarioText → npc-parser → facts[] → quest-system → interpretedFacts
    → factMatch → 분기·보상
    ※ LLM은 판정에 끼지 않음

  ┌─ 성공 (completion.completed === true) ─────────────────────────┐
  │  · 골드·cargo_destination 반영                                  │
  │  · 의뢰인 성향별 completionDialogue 재생 (알릭 장면에서)        │
  │  · 예: 경비 의뢰 + 12개 보고 → 15로 해석 → 150골드, 관청        │
  └──────────────────────────────────────────────────────────────────┘

  ┌─ 실패 (completion.completed === false) ─────────────────────────┐
  │  · 골드 0 · 완료 대사 없음 · QuestState.completed = false       │
  │  · completion.reason 표시 (예: subject missing 마약)           │
  │  · HTTP 200 / body.ok === true 여도 동일 — 반드시 completed 확인 │
  └──────────────────────────────────────────────────────────────────┘

5. 시나리오 (발표·테스트용)
--------------------------------------------------------------------------------

  【A — 메인】 경비 의뢰 + 12개 보고
    보고문: "안개 계곡에 밀수 화물이 버려져 있다. 마약초 열두 개가 들어 있다"
    결과: authority_path · 150골드 · 관청 · 완료 대사

  【B — 분기】 학자 의뢰 + 5개 보고
    보고문: "... 마약초 다섯 개가 들어 있다"
    결과: black_market_path · 300골드 · 암시장

  【C — 실패】 경비 의뢰 + 엉뚱한 보고
    보고문: "아무거나" (예시 문장 남기지 말 것)
    결과: completed=false · 골드 없음 · 「보고 실패」

  의뢰인별 (12개 보고 시)
  ┌──────────────┬─────────────────────┬──────────────────────────┐
  │ 의뢰인       │ 브리핑 톤           │ 해석 → 결말 (12개 보고)  │
  ├──────────────┼─────────────────────┼──────────────────────────┤
  │ 소심한 경비  │ "잔뜩일 거야" (과장)│ 15개 → 150골드 · 관청    │
  │ 탐욕한 상인  │ "금빛 상자…"       │ 15개 → 150골드 · 관청    │
  │ 학자 알릭    │ "숫자는 정확히"     │ 12개 → 150골드 · 관청    │
  └──────────────┴─────────────────────┴──────────────────────────┘
  ※ 브리핑은 연출. 판정은 ③ 보고문만 사용.


6. 결말·통과 조건
--------------------------------------------------------------------------------
  분기 (interpretedFacts 기준)
    많음 (qty≥10 등)     → 관청 · 150골드
    적음 (예: 5개)       → 암시장 · 300골드
    애매                 → fallback · 80골드

  보고 통과 (factMatch, 둘 중 하나)
    · subject에 「마약」 + minQuantity/minCertainty
    · 또는 subject 「화물」+ target 「계곡」 (factMatchAlt)
    ※ 「마약」 한 단어만으로도 통과 가능 (데모용 느슨한 조건)

  보고 실패
    · 빈 문자열 → turn-in 보내지 않음
    · 엉뚱한 문장 → completed=false, reason에 사유


7. Turn-in API (요약)
--------------------------------------------------------------------------------
  POST http://127.0.0.1:8787/v1/quest/turn-in
  서버: models/npc-test 에서 run-api.cmd 또는 node npc-api-server.mjs

  {
    "questId": "quest_abandoned_cargo",
    "giverId": "guard_timid",
    "scenarioText": "안개 계곡에 밀수 화물이 버려져 있다. 마약초 열두 개가 들어 있다",
    "sessionKey": "player-save-slot-1"
  }

  UE 반영 (의사코드)
    res = POST turn-in(...)
    if (res.completion.completed) {
      Gold += res.outcome.rewards.gold
      WorldFlags.cargo_destination = res.outcome.worldFlags.cargo_destination
      ShowDialogue(giverCompletionLine)  // giver별 completionDialogue
    } else {
      ShowFailMessage(res.completion.reason)
      // 골드·완료 대사 금지
    }

  상세 필드·SaveGame: INTEGRATION-GUIDE.txt §6~7

10. 발표용 핵심 4줄
--------------------------------------------------------------------------------
  1) 의뢰 때 의뢰인이 먼저 수량을 지레짐작한다 (giver_presume).
  2) 보고 직후 알릭이 해석 수량을 말한다 (alric_presume) — 맨 끝 X.
  3) 같은 12개 보고도 의뢰인에 따라 기록 15 vs 12.
  4) 완료 = completion.completed 만.
