================================================================================
  Project-Nova / models/npc-test — 정보·퀘스트 엔진 설계 정리

1. 이것이 무엇인가
--------------------------------------------------------------------------------
- 브라우저 + Node 프로토타입. 결정론 왜곡 엔진 + quest_abandoned_cargo.
- LLM은 interpretedFacts JSON만으로 대사 연출.


2. 모듈
--------------------------------------------------------------------------------
  quest-system.js       왜곡·전파·KB·executeScenario·source_chain 규칙
  game-clock.js         세션 tick / day·hour (UE GameTimeTick 대체)
  knowledge-layers.js   WorldTruth + PlayerKnowledge
  llm-fact-anchor.js    LLM 대사 vs Grounded DATA 검증
  quest-runtime.js      퀘스트·acceptQuest·advanceProcessStep·runQuestFlow
  quest-game-state.js   gold/xp/worldFlags/questHistory (로컬, UE 전)
  app.js                NpcParser
  quests-draft.json     정식 퀘스트
  npcs.json (v3)        주제별 reputation + persona
  player-profile.json   플레이어 전파 + initialNpcReputation
  reputation-config.json  tier 의뢰 대사
  GAME-API.json         향후 UE용 JSON 계약 (브릿지 없음)
  README.md             사용법


3. 퀘스트 플로우 (로컬 완료)
--------------------------------------------------------------------------------
  acceptQuest → dialogue → travel → fact_input(runQuestTurnIn)
  → outcome 분기 → QuestGameState.applyTurnInOutcome

  의뢰인 neutral: giver.acceptDialogue (3색 브리핑)
  processSteps[].npcLine = 의뢰 시점 소문 연출


4. 지식·시간·앵커링 (프로토타입 완료)
--------------------------------------------------------------------------------
  - GameClock: sessionKey별 tick, UI/executeScenario 동기화
  - WorldTruth: GM/파서 시드 vs PlayerKnowledge 비교
  - PlayerKnowledge: 플레이어 turn-in·수신 시 interpretedFacts 누적
  - source_chain / hop_depth: 다단 전파 시 certainty·규칙(source_chain_*)
  - LlmFactAnchor: mock/live 출력 수치·주어 검증 (실패 시 mock 폴백)


5. 미구현 (의도)
--------------------------------------------------------------------------------
  - 언리얼 C++/Blueprint/HTTP 브릿지
  - 맵 이동·아이템·3D 대화 UI (UE 담당)


6. 테스트: node run-all-tests.mjs
--------------------------------------------------------------------------------
  distortion (11), integration (9), quest, reputation, accept-dialogue,
  process-steps, profiles-sync, quest-flow,
  knowledge-layers, source-chain, llm-anchoring
