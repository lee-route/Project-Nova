■ 한 줄 요약
--------------------------------------------------------------------------------
  퀘스트 보고는 POST /v1/quest/turn-in 한 번만 호출하면 됩니다.
  completion.completed == true 이면 응답 dialogue.npcSpeech 에 알릭 LLM 대사가
  이미 들어 있습니다. UE는 그 문자열을 대화 UI에 띄우면 끝.


■ 0. 사전 준비
--------------------------------------------------------------------------------
  (1) Node API 서버 실행 (개발 PC)

      cd models\npc-test
      node npc-api-server.mjs

  (2) LLM live (선택 — OpenAI 비용 발생)

      copy llm-config.example.json llm-config.local.json
      → apiKey, useLive: true 설정 후 서버 재시작

      live 없으면 provider: mock (무료, 테스트용 고정 톤 대사)

  (3) 확인

      GET http://127.0.0.1:8787/health        → llmEnabled
      GET http://127.0.0.1:8787/v1/llm/status


■ 1. UE Blueprint 흐름 (권장)
--------------------------------------------------------------------------------

  [1] 퀘스트 수락 (UE 로컬 또는 GET accept-dialogue)
  [2] 플레이어 조사 · 맵 연출 (UE)
  [3] 보고 UI → scenarioText 수집
  [4] HTTP POST /v1/quest/turn-in  ← ★ 여기 한 번만
  [5] JSON 파싱 → 아래 분기

      completion.completed == false
        → 실패 UI, 골드·완료 대사 금지

      completion.completed == true
        → outcome.rewards.gold, outcome.worldFlags 저장 (UE SaveGame)
        → dialogue.npcSpeech 를 알릭 대화창/자막에 표시


■ 2. Turn-in 요청 JSON
--------------------------------------------------------------------------------

  URL:    POST http://127.0.0.1:8787/v1/quest/turn-in
  Header: Content-Type: application/json; charset=utf-8

  {
    "questId": "quest_abandoned_cargo",
    "giverId": "guard_timid",
    "scenarioText": "안개 계곡에 밀수 화물이 버려져 있다. 마약초 열두 개가 들어 있다",
    "sessionKey": "ue-player-save-slot-1"
  }

  · giverId = 의뢰인 (guard_timid | merchant_greedy | scholar_alric)
  · 보고 수신 NPC는 서버가 turnInProfileKey 로 처리 (보통 scholar_alric)
  · includeDialogue: false 를 넣으면 LLM 생략 (판정만 빠르게 테스트할 때)


■ 3. Turn-in 응답 — UE가 쓸 필드
--------------------------------------------------------------------------------

  ok                          true
  completion.completed        true/false  ← 최우선 분기
  outcome.rewards.gold        숫자
  outcome.worldFlags.cargo_destination   authority | black_market | unknown
  outcomeBranch.branchId      authority_path | black_market_path | fallback

  dialogue (완료 시 기본 포함, includeDialogue:false면 null)
    .ok                       true
    .npcProfileKey            scholar_alric
    .npcSpeech                "…알릭 대사…"  ← UI에 표시
    .provider                 openai | mock | mock_fallback
    .questJudgmentExcluded    true (대사는 연출만, 판정과 무관)

  llmExcluded                 dialogue 없으면 true


■ 4. PowerShell 스모크 테스트 (UE 전에 확인)
--------------------------------------------------------------------------------

  $body = @{
    questId = "quest_abandoned_cargo"
    giverId = "guard_timid"
    scenarioText = "안개 계곡에 밀수 화물이 버려져 있다. 마약초 열두 개가 들어 있다"
    sessionKey = "ue-smoke-1"
  } | ConvertTo-Json -Compress

  $r = Invoke-RestMethod -Uri "http://127.0.0.1:8787/v1/quest/turn-in" `
    -Method POST -Body $body -ContentType "application/json; charset=utf-8"

  $r.completion.completed    # True
  $r.outcome.rewards.gold   # 150 등
  $r.dialogue.npcSpeech     # 알릭 대사


■ 5. Blueprint 체크리스트
--------------------------------------------------------------------------------
  [ ] VaRest 또는 HTTP Request 노드로 POST turn-in
  [ ] Json Object → Get Bool Field "completion" → "completed"
  [ ] false: 실패 위젯, return
  [ ] true: Get Number Field outcome.rewards.gold → SaveGame
  [ ] true: Get String Field dialogue.npcSpeech → Text Block / 대화 시스템
  [ ] (선택) provider == openai 이면 디버그 로그


■ 6. 자주 하는 실수
--------------------------------------------------------------------------------
  · turn-in 후 POST /v1/dialogue 를 또 호출  → v1부터 turn-in에 포함됨 (중복 가능)
  · completion.completed 무시하고 gold 적용   → 보고 실패인데 보상 지급됨
  · giverId 를 scholar_alric 으로 착각       → giverId=의뢰인, 알릭=수신 NPC
  · API 서버 안 켠 상태에서 UE 테스트         → Connection refused
  · file:// 웹 데모로 LLM 기대               → LLM은 API(8787) 경로, 웹(5500)은 판정만
