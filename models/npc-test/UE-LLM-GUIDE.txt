■ 한 줄 요약
--------------------------------------------------------------------------------
  의뢰: GET accept-dialogue → giverPresentation (의뢰인 지레짐작 수량)
  보고: POST turn-in → reportBeats (플레이어 → 알릭 지레짐작 → 결과)
  UE는 beats 순서대로 TextBlock에 SetText.


■ 0. 사전 준비
--------------------------------------------------------------------------------
  cd models\npc-test
  node npc-api-server.mjs
  GET http://127.0.0.1:8787/health → ok: true


■ 1. 연출 타임라인 (순서 엄수)
--------------------------------------------------------------------------------

  [① 의뢰 NPC]  GET /v1/quest/accept-dialogue?giverId=guard_timid
      accept.line                          짧은 수락 대사
      accept.giverPresentation.presumedLine   ★ "15개 될 거야" (경비/상인)
      accept.giverPresentation.presumedQuantity
      accept.giverPresentation.acceptBeats[0]  phase: giver_presume

  [② 조사]      UE 맵 (API 없음)

  [③ 알릭 보고]  입력 UI → scenarioText
      POST /v1/quest/turn-in

  [④ beats]     reportPresentation.reportBeats 순서대로:

      order 1  player_report    [플레이어] 마약초 열두 개…
      order 2  alric_presume    ★ [학자 알릭] …15개군…  (보고 직후!)
      order 3  distortion_hint  (선택) 12 ↔ 15 작은 UI
      order 4  alric_dialogue   LLM/mock 대사
      order 5  giver_echo       의뢰 회수
      order 6  outcome          화물 행선

  [⑤ 게임]      completion.completed → gold / SaveGame


■ 2. Accept 요청 (의뢰)
--------------------------------------------------------------------------------
  GET http://127.0.0.1:8787/v1/quest/accept-dialogue?giverId=guard_timid&sessionKey=ue-1

  PowerShell:
  $a = Invoke-RestMethod "http://127.0.0.1:8787/v1/quest/accept-dialogue?giverId=guard_timid"
  $a.accept.giverPresentation.presumedLine
  $a.accept.giverPresentation.presumedQuantity   # 경비 15, 알릭 12


■ 3. Turn-in 요청 (보고)
--------------------------------------------------------------------------------
  POST http://127.0.0.1:8787/v1/quest/turn-in

  {
    "questId": "quest_abandoned_cargo",
    "giverId": "guard_timid",
    "scenarioText": "안개 계곡에 밀수 화물이 버려져 있다. 마약초 열두 개가 들어 있다",
    "sessionKey": "ue-1"
  }

  PowerShell:
  $r = Invoke-RestMethod -Uri "http://127.0.0.1:8787/v1/quest/turn-in" -Method POST `
    -Body (@{ questId="quest_abandoned_cargo"; giverId="guard_timid";
      scenarioText="안개 계곡에 밀수 화물이 버려져 있다. 마약초 열두 개가 들어 있다";
      sessionKey="ue-1" } | ConvertTo-Json -Compress) `
    -ContentType "application/json; charset=utf-8"

  $r.reportPresentation.reportBeats[1].line      # 알릭 presume
  $r.reportPresentation.interpretedRecord.quantity
  $r.completion.completed
  $r.outcome.rewards.gold


■ 4. UE Blueprint 체크리스트
--------------------------------------------------------------------------------
  [ ] 의뢰: GET accept → giverPresentation.presumedLine 표시
  [ ] 보고: 알릭만 입력 UI (경비/상인 X)
  [ ] POST turn-in
  [ ] reportBeats for-loop → phase별 TextBlock
  [ ] alric_presume 에서 quantity 큰 숫자 표시
  [ ] completed false → 골드·완료 금지
  [ ] completed true → outcome.rewards.gold SaveGame
