■ 0. 뭐가 뭔지 (30초)
--------------------------------------------------------------------------------
  [웹 index.html]     판정·골드·분기 + 의뢰 시 지레짐작 수량 미리보기
  [API npc-api]       UE 연동 — accept(의뢰) + turn-in(보고) 한 세트
  [quest-presentation] 수량 연출 beats (의뢰인·알릭 지레짐작)


■ 1. 코드 받기
--------------------------------------------------------------------------------
  git pull origin main
  cd models\npc-test


■ 2. 수량 왜곡 — 플레이어가 보는 순서 (핵심)
--------------------------------------------------------------------------------
  ① 의뢰 (경비/상인)   소문 12 → NPC가 「15개 될 거야」 (giver_presume)
  ② 조사               UE 맵
  ③ 보고 (알릭)        플레이어 「12개」 입력
  ④ 알릭 직후          알릭 「15개군…」 (alric_presume) ← 보고 직후, 결과 전
  ⑤ 결과               골드·화물 행선

  ※ 알릭 의뢰(faithful)는 ①에서 12 유지, ④도 12


■ 3. 웹 데모 (판정 테스트 · 무료)
--------------------------------------------------------------------------------
  python -m http.server 5500
  http://127.0.0.1:5500/index.html  (Ctrl+F5)

  · 의뢰인 바꾸면 「의뢰 대사」에 지레짐작 수량 표시
  · 성공 보고: 안개 계곡… 마약초 열두 개…
  · 완료 배너: 플레이어 → 알릭 지레짐작 → 결과 순서
  · 카드: 보고 수량 vs 기록 수량


■ 4. API 서버
--------------------------------------------------------------------------------
  node npc-api-server.mjs
  http://127.0.0.1:8787/health


■ 5. UE 팀 — API 2번만
--------------------------------------------------------------------------------
  ① GET  /v1/quest/accept-dialogue?giverId=guard_timid
       → accept.giverPresentation.presumedLine (의뢰인 15개)

  ② POST /v1/quest/turn-in
       → reportPresentation.reportBeats (플레이어→알릭→결과)
       → completion.completed / outcome.rewards.gold

  ★ UE-LLM-GUIDE.txt (1페이지)
  ★ QUEST-FLOW-GUIDE.txt (시나리오·발표)
  ★ INTEGRATION-GUIDE.txt (HTTP 상세)


■ 6. LLM (선택)
--------------------------------------------------------------------------------
  llm-config.local.json (git 제외) 또는 env OPENAI_API_KEY
  live 없으면 mock (무료)
  turn-in 응답 dialogue.npcSpeech 에 포함 (별도 /v1/dialogue 불필요)


■ 7. 자주 하는 실수
--------------------------------------------------------------------------------
  · 수량을 맨 마지막 엔진 메모에만 넣음     → giver_presume / alric_presume 비트 사용
  · 경비에게 보고 입력 UI 붙임               → 보고는 알릭만
  · completion.completed 무시               → 실패인데 골드 지급
  · llm-config.local.json 깃 push          → 키 유출
