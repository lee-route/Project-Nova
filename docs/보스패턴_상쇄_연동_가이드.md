# 보스 패턴 ↔ 상쇄 시스템 연동 가이드

> **대상:** Paragon Grux 보스 AI·패턴 작업 담당  
> **담당 브랜치:** `현진` (음성·상쇄 C++)  
> **최종 갱신:** 2026-06-09

---

## 1. 한 줄 요약

상쇄 시스템은 **Paragon Grux 에셋 보스**에게만 동작합니다.  
패턴 텔레그래프(선딜) 직후 `RequestCounterWindow(Pattern_N)` 한 번 호출 → 플레이어가 맞는 무기(키보드 1~4 또는 음성)로 응답 → 성공 시 `OnGruxCounterSucceeded`에서 보스 반응(스턴·취소 등)을 BP로 처리합니다.

---

## 2. 패턴 ↔ 상쇄 무기 매핑

`상쇄 시스템.txt` 및 C++ enum 기준:

| 보스 패턴 | C++ enum | 상쇄 무기 | 키 | 음성 예시 |
|-----------|----------|-----------|-----|-----------|
| 돌진 | `Pattern_1` | 방패 | 4 | "방패" |
| 범위공격 | `Pattern_2` | 창 | 3 | "창" (STT 오인식 보정 있음) |
| 투사체 | `Pattern_3` | 활 | 2 | "활" |
| 패턴_@ (미정) | `Pattern_4` | 검 | 1 | "검" |

- 상쇄 창 지속 시간: **약 1.2초** (`Config/DefaultNovaVoice.ini` → `CounterWindowSeconds`)
- Grux 보스와 플레이어 거리: **4500cm 이내** (`MaxCounterBossDistance`)

---

## 3. Grux 보스 BP 필수 세팅 (1회)

### 3-1. 컴포넌트 추가

Grux 보스 Blueprint에 아래 컴포넌트를 추가합니다.

- **클래스:** `Nova Paragon Grux Boss Component` (`UNovaParagonGruxBossComponent`)

BeginPlay 시:

- Actor 태그 `ParagonGruxBoss` 자동 부여
- 스켈레탈 메시 경로에 `ParagonGrux` 포함 여부 검사 (경고 로그)

> Sevarog·Kwang 등 **다른 Paragon 보스에는 이 컴포넌트를 붙이지 마세요.** 상쇄가 열리지 않습니다.

### 3-2. 메시 확인

Skeletal Mesh가 `Content/ParagonGrux/...` 계열이어야 합니다.  
다른 메시를 쓰는 경우 `bValidateParagonGruxMesh`를 끄거나 메시를 Grux로 교체하세요.

## 4. 패턴 BP에서 호출하는 방법 (권장)

### 방법 A — 컴포넌트 API (권장)

보스 패턴 몽타주·타임라인·AI 상태 전환에서 **텔레그래프 직후**:

```
[Nova Paragon Grux Boss Component]
  → Request Counter Window
      Counter Type: Pattern_1 (또는 2, 3, 4)
```

- Player Controller·Boss Actor를 직접 찾을 필요 없음
- 거리·Grux 검증은 C++에서 처리

### 방법 B — Player Controller 직접 호출

```
Get Player Controller → Cast to Nova Click Move Player Controller
  → Open Boss Counter Window
      Counter Type: Pattern_N
      Boss Source: Self (Grux 보스 Actor)
```

`Boss Source` 없이 호출하면 **거부**됩니다.

## 5. 상쇄 성공 후 보스 반응

`Nova Paragon Grux Boss Component`의 이벤트:

- **`On Grux Counter Succeeded`**
  - `Counter Type` (Pattern_1~4)
  - `Weapon Used` (Shield / Spear / Bow / Hammer=검)

여기서 예시 연출:

- 공격 몽타주 취소
- 짧은 스턴 / 경직
- 피해 또는 슈퍼아머 파괴
- VFX·SFX

플레이어 쪽 연출은 `BP_NovaPlayerController`의 `On Boss Counter Visual Success`에서 처리합니다. (보스팀과 역할 분리)

---

## 6. 호출 타이밍 (중요)

| 시점 | 동작 |
|------|------|
| 패턴 **텔레그래프 시작** (돌진 예고, 범위 표시 등) | `RequestCounterWindow` 호출 |
| 상쇄 창 1.2초 이내 | 플레이어 무기 입력 대기 |
| 성공 | `OnGruxCounterSucceeded` → 보스 패턴 중단/반격 |
| 실패·시간 초과 | 보스 패턴 **그대로 진행** (C++는 창만 닫음) |

**주의**

- 같은 패턴에서 `RequestCounterWindow`를 **중복 호출**하지 마세요. (이전 창이 닫히고 새 창이 열림)
- 플레이어가 Grux에서 멀어지면 창이 자동으로 닫힙니다.

## 7. 테스트 방법

### 에디터 스모크 테스트

1. 맵에 **Grux 보스** (`NovaParagonGruxBossComponent` 포함) 배치
2. PIE 실행, Grux **근처**에서:
   - **F5** → Pattern_1 / **4** 또는 "방패"
   - **F6** → Pattern_2 / **3** 또는 "창"
   - **F7** → Pattern_3 / **2** 또는 "활"
   - **F8** → Pattern_4 / **1** 또는 "검"
3. 화면 메시지:
   - 성공: `상쇄 성공: 돌진(Pattern_1) - 방패로 상쇄`
   - 실패: `상쇄 실패: ...` / `Grux 보스와 거리가 너무 멉니다`

Grux가 없으면 F5~F8 시 `상쇄 테스트: Paragon Grux 보스가 근처에 없습니다` 표시.

### 음성 테스트

- `Config/LocalNovaVoice.ini`에 Azure 키 설정 ([`Azure Speech 설정 방법.txt`](../Azure%20Speech%20설정%20방법.txt) 참고)
- PIE 후 마이크로 무기 명령

## 8. C++ API 레퍼런스 (보스팀 참고)

| API | 위치 | 용도 |
|-----|------|------|
| `UNovaParagonGruxBossComponent::RequestCounterWindow` | Grux 보스 | 패턴 → 상쇄 창 오픈 |
| `OnGruxCounterSucceeded` | Grux 보스 | 상쇄 성공 시 보스 반응 |
| `ANovaClickMovePlayerController::OpenBossCounterWindow` | PlayerController | BossSource 필수 |
| `UNovaCombatVoiceGateComponent::GetPatternFullLabel` | 정적 | UI 문구 |
| `UNovaCombatVoiceGateComponent::GetRequiredWeaponCounterLabel` | 정적 | UI 문구 |

**Blueprint enum:** `ENovaBossCounterType` → `Pattern_1`, `Pattern_2`, `Pattern_3`, `Pattern_4`
